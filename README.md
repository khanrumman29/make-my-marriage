# Make My Marriage 💍

> A private, collaborative wedding-planning workspace for a couple and their family.

## Tech Stack
- **Frontend:** React 18, Vite, Tailwind CSS, React Router DOM, Lucide React
- **Backend & Auth:** Supabase (PostgreSQL, Row Level Security, Supabase Auth)
- **Design Tokens:** Warm Ivory Canvas (`#F8F6F0`), Forest Green (`#24483F`), Muted Gold (`#B79A62`), Ink (`#252923`)
- **Typography:** Playfair Display (Serif Headings) & Plus Jakarta Sans (UI Sans)

## Primary Navigation Sections
1. **Dashboard:** Overview metrics, budget progress, upcoming functions, recent expenses & to-do list.
2. **Expenses:** Filterable expense management, payment status tracking, and breakdown.
3. **Functions:** Wedding ceremony schedules, planned budgets, and linked expenses.
4. **Invitations:** Digital invitation builder with live preview and shareable links.
5. **Family & Settings:** Family collaboration roles, group messaging board, and wedding configuration.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
